## التشغيل محلياً | Run locally

لا يحتاج المشروع إلى أي تثبيت. افتح `index.html` مباشرة، أو شغّل خادماً بسيطاً:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## النشر | Deployment

الموقع ثابت بالكامل، لذا يمكن نشره كما هو على:

- **GitHub Pages** — Settings ← Pages ← اختر الفرع والمجلد الجذر `/`.
- **Netlify / Vercel** — اسحب المجلد أو اربط المستودع (بدون أمر بناء).
- **أي استضافة تقليدية** — ارفع الملفات عبر FTP إلى `public_html`.

بعد ربط النطاق `nabalnamir.com` لا حاجة لأي تعديل إضافي.

## ملاحظات للتحديث | Update notes

- **الشعار:** الملف `assets/img/logo-mark.svg` هو إعادة رسم متجهية للشعار.
  عند توفّر الملف الأصلي بدقة عالية (PNG/SVG)، ضعه في `assets/img/`
  وحدّث مسارات `<img>` في `index.html` والفوتر.
- **صور المنتجات:** أشكال العبوات الحالية مرسومة بـ CSS. لاستبدالها بصور حقيقية،
  ضع الصور في `assets/img/` واستبدل عناصر `<div class="p-shape …">` بوسوم `<img>`.
- **النصوص:** كل عنصر قابل للترجمة يحمل السمتين `data-ar` و `data-en`؛
  عدّل كليهما معاً عند تغيير أي نص.
- **الخريطة:** رابط «افتح الموقع على خرائط جوجل» في قسم التواصل يشير إلى موقع المصنع
  الدقيق، وكذلك الحقل `hasMap` في البيانات المنظمة. أما الخريطة المضمّنة (الـ iframe)
  فما زالت تتمركز على منطقة عويريج عموماً. لتثبيت الدبوس عليها: افتح الموقع على
  Google Maps ← Share ← Embed a map، وانسخ قيمة `src` من الـ iframe إلى الإطار
  الموجود في قسم «تواصل معنا» داخل `index.html`.
- **أوقات العمل والأرقام:** موجودة في قسم "تواصل معنا" والفوتر.
