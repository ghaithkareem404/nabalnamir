## نظرة عامة | Overview

موقع ثابت (Static) مبني بـ HTML و CSS و JavaScript خالص — بدون أي أدوات بناء أو
اعتماديات، ما يجعله سريعاً جداً وسهل الاستضافة على أي خدمة.

A static site built with plain HTML, CSS and JavaScript — no build step and no
dependencies, so it is fast and can be hosted anywhere.

## لغة التصميم | Design language

الموقع مبني على قواعد تحريرية مقصودة، لا على قوالب جاهزة:

- **الخط**: `IBM Plex Sans Arabic` للعربية و `IBM Plex Sans` للاتينية — تدرّج حجمي محدد
  (عنوان رئيسي، عناوين أقسام، متن، تسميات صغيرة) بدل أحجام عشوائية.
- **اللون**: خلفية ورقية دافئة `#FBFAF8` مع كحلي العلامة `#0C2F5C` وأزرق واحد للتمييز.
  لا تدرّجات لونية ولا نصوص متدرجة.
- **الفواصل**: خطوط شعرية (hairlines) وشبكة منتظمة بدل البطاقات ذات الظلال.
- **الأيقونات**: مرسومة يدوياً بـ SVG أحادي السُمك — لا إيموجي.
- **رسوم العبوات**: كل عبوة مرسومة SVG (غطاء، حلقة عنق، ملصق، مقبض)، وأحجامها
  النسبية على الشبكة تعكس السعة الفعلية، مع محاذاة العناوين على خط واحد.
- **الحركة**: ظهور خفيف عند التمرير فقط — بلا فقاعات أو نبضات أو عناصر طائرة.
- **الترقيم**: أقسام مرقّمة بالأرقام العربية (٠١…٠٦) وبالإنجليزية (01…06).

## هيكل المشروع | Structure

```
index.html              الصفحة الرئيسية بكل الأقسام
404.html                صفحة الخطأ
assets/css/style.css    التنسيقات وهوية الألوان المستمدة من اللوغو
assets/js/main.js       تبديل اللغة، القائمة، الفلترة، النموذج
assets/img/logo-mark.svg  الشعار (نسخة SVG)
assets/img/favicon.svg    أيقونة الموقع
robots.txt, sitemap.xml
```

## التشغيل محلياً | Run locally

لا يحتاج المشروع إلى أي تثبيت. افتح `index.html` مباشرة، أو شغّل خادماً بسيطاً:

```bash
python3 -m http.server 8000
# ثم افتح http://localhost:8000
```

## النشر | Deployment

الموقع ثابت بالكامل، لذا يمكن نشره كما هو على:

- **GitHub Pages** — Settings ← Pages ← اختر الفرع والمجلد الجذر `/`.
- **Netlify / Vercel** — اسحب المجلد أو اربط المستودع (بدون أمر بناء).
- **أي استضافة تقليدية** — ارفع الملفات عبر FTP إلى `public_html`.

بعد ربط النطاق `nabalnamir.com` لا حاجة لأي تعديل إضافي.

## ملاحظات للتحديث | Update notes

- **الشعار:** الملف `assets/img/logo-mark.svg` هو إعادة رسم متجهية للشعار.
  عند توفّر الملف الأصلي بدقة عالية (PNG/SVG)، ضعه في `assets/img/`
  وحدّث مسارات `<img>` في `index.html` والفوتر.
- **صور المنتجات:** رسوم العبوات الحالية متجهية (SVG) داخل `index.html`. أفضل ترقية
  ممكنة للموقع هي تصوير احترافي للعبوات وخط الإنتاج؛ لاستبدال الرسم بصورة، ضع الصورة
  في `assets/img/` واستبدل `<svg class="pack …">` بوسم `<img>` بالأبعاد نفسها.
- **النصوص:** كل عنصر قابل للترجمة يحمل السمتين `data-ar` و `data-en`؛
  عدّل كليهما معاً عند تغيير أي نص.
- **الخريطة:** زر «اعرض الخريطة» في قسم التواصل يحمّل خريطة جوجل عند الضغط فقط
  (أسرع وأفضل للخصوصية). رابط «افتح الموقع على خرائط جوجل» يشير إلى موقع المصنع
  الدقيق. لتثبيت دبوس الخريطة المضمّنة على الموقع نفسه، افتح الموقع على Google Maps
  ← Share ← Embed a map، وانسخ قيمة `src` من الـ iframe إلى الثابت `MAP_EMBED`
  في أعلى `assets/js/main.js`.
- **أوقات العمل والأرقام:** موجودة في قسم "تواصل معنا" والفوتر.
